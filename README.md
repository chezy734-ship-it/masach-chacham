# 💡 מסך חכם – Smart Screen Manager
**גרסה 1.3.0 | Windows 10/11 | PyQt6**

## הפעלה
```
pip install PyQt6 pillow pystray
python masach_chacham.py
```
לבניית EXE: לחץ פעמיים על `build_exe.bat`

## שינויים בגרסה 1.3
| # | שינוי |
|---|-------|
| 1 | גרסה 1.3.0 בכל מקום |
| 2 | **סרגל צידי ימני בעברית, שמאלי באנגלית** |
| 3 | **הגדרות מודעה + כיבוי מחדש עברו לתוך כל משימה בנפרד** |
| 4 | **כיבוי בכפיה** (force_off) – גובר על פעילות משתמש |
| 5 | **ניסיון חוזר** לכיבוי אם המשתמש היה פעיל |
| 6 | **כל ההגדרות האלו קיימות גם בלשונית טיימר** |
| 7 | **screen_off משתמש ב-PostMessageW** – לא מכניס למצב שינה |
| 8 | זמן הודעה ו-reoff בפורמט דקות:שניות (MM:SS) |

## שדות חדשים לכל משימה
- `notif` – הצג הודעה לפני כיבוי (MM:SS לפני)
- `force_off` – כיבוי בכפיה (גובר על פעילות)
- `reoff` – כבה מחדש לאחר פעילות (MM:SS)
- `retry_off` – נסה שוב אחרי N שניות (מוסתר כשforce_off מסומן)
